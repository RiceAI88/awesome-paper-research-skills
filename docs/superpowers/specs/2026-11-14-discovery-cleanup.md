# 专业导航八项改进
用户已批准此前逐项讨论的八项建议。第一项按推荐的方案二：场景常显；平台、排序、收藏收入可关闭的筛选面板，显示已生效条件数；视图切换常显。手机面板从底部展示，吸顶时场景和搜索仍可用。
第二项去掉专业按钮常显数字，汇总明确当前结果=专业适用+通用，悬停仍可查专用数量。第四项规则收进可点击分类说明。
第三项审核现有项目官方README、补真实专业映射，针对空白专业增补检索词和候选记录；不硬凑数量，不改变项目原文简介与准入限制。页面零收录说明本站尚无已核验专业归属，而非全球不存在；提供通用项目与推荐入口。
第五项顶部支持卡缩为支持本站↗轻入口，服务说明悬停查看，弹窗保留。第六项标题“找到适合你专业的科研 Skills”；副标题“从找文献、读论文到写作与数据分析，按专业和任务发现 GitHub 开源工具。”
第七项交流群小字“一起发现好用的科研 Skills”，标题“加入各专业科研 Skills 交流群”，描述“交流使用经验，分享或推荐你所在专业的 Skills。”保留二维码。
第八项导航名“科研 Skills 导航”，仓库名URL不变，完整英文名保留页脚README，GitHub前加“推荐 Skill”，链接原生GitHub Issue模板，说明核验后收录。
