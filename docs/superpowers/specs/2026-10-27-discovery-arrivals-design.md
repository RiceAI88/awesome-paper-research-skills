# 候选发现与今日新增

用户已确认扩展最近更新/Stars 分段发现、README 核验、双轨准入，并要求突出每日新收录。

- 保留已有热门搜索，另以 6 组精准查询按最近更新和 4 个 Stars 段发现；每次搜索的排序、截断和错误可审计。
- 候选先去重再按科研信号优先核验；README 核验每次最多 120 次，缓存 14 天、上游 push 变化失效。未核验/失败不冒充已核验；仍合格的旧项目不因 README 暂时不可用而删除。
- Skill 轨：明确学术用途与 Skill/Agent 能力；相关项目轨：明确学术工作场景与工具/指南/工作流用途。README 引用、致谢等区块不作为准入证据；硬门槛 100 Stars、非 fork、未归档、显式排除不变。原简介不改写。
- 沿用原 Stars 排序和 150 项展示上限，保留超限报告。
- 首次收录时间新增精确时间字段，按北京时间自然日展示。历史只有日期的记录保留原日期，不伪造精确时间；恢复/改名不重置首次收录。
- 榜单上方用紧凑靛紫模块显示今日新增 Skills，最多展示 3 个入口和查看全部按钮；相关项目单独计数、可筛选。卡片与表格显示今日新收录标识。无新增如实显示，无项目不得伪称今日新增。
- 默认仍为完整榜单，不把今日新增误作排名依据；新筛选支持链接分享/清除，并与已有筛选一致。

方案取舍：只增加固定关键词仍会重复热门项目；取消过滤会引入大量无关仓库。因此采用分层搜索+有请求预算的文档核验，复用现有数据与页面组件。保留现有主题和广告位置。
