# 榜单浏览与连续查看详情

目标：滚动长榜单时仍能操作筛选并辨认表头；按当前筛选和排序连续阅读项目，关闭抽屉后保持原浏览位置。

方案：复用 Ant Design Table sticky 和原 Drawer。相比自制固定表头，复用内置横向同步和宽度计算更简单；不复制一套筛选控件，避免状态与焦点重复。

范围：筛选栏在主内容内吸顶，表头贴在筛选栏下方，动态测量实际高度以适应中英文、手机和窗口变化。保持当前筛选栏的位置、字段、颜色与布局。详情头部新增上一个/下一个和当前位置，依当前结果次序导航，首尾禁用、不循环。通过分享链接打开当前结果以外的项目时明确提示并禁用导航。切换项目将详情内容滚回顶部，背景保持原位置；关闭使用原抽屉的焦点恢复并验证实际滚动位置，只有证据显示不足时才补额外恢复机制。

不修改：数据口径、采集、图表、对比、编辑内容、原始简介、SEO。保留延迟加载与首屏预算。遵循用户已批准的榜单浏览和连续详情体验范围。
