# Warm data observatory — approved visual design

The user approved the final warm rose/mulberry mockup and requested red suspected-stale labels. Implement the approved dashboard architecture: compact header/search/tasks, four plain statistics, 2×2 data charts (trend and donut, growth bars and scatter), editorial selections, automatic ranking and concise ranking/source notes. Keep APRS/full name, original repository descriptions, existing functionality and provenance attribution.

Chosen direction: restrained white editorial presentation with thin rules, warm charcoal, muted mulberry #866178, rose #B47C7D and pink peach #D3A49F. No cyan/blue/ochre or electric purple; red is reserved for suspected-stale tags. Alternate full-purple and cool accents were rejected during visual iterations. Use the existing exact system font stack.

Use @ant-design/plots Line/Pie/Bar/Scatter. Actual current filtered repositories drive all charts; top three by Stars supply historical lines; actual dated snapshots are shown without interpolation or invented values. Selectable trailing 30/60-day history window anchored to dataset date. Current 7-day growth is a fixed metric, explicitly labeled independent of history window. Bars show top five positive-growth repos; scatter includes zero and negative deltas on a linear y-axis, logarithmic positive Stars x-axis. Category IDs and full repo names identify colors and interactions; consistent repo colors for trend/bar. Category selection updates existing filters; chart/list clicks open existing details. Plain text legends and tables of current values supply keyboard access. Empty/missing histories get empty states; error boundary isolates chart failures. Dark mode remains functional with matching warm palette.

Scope excludes new ranking algorithm, new API, translated summaries and data collection changes. Initial metrics reflect the full dataset, charts reflect current filters with an explicit result count. Red stale badges use the existing stale boolean without changing its threshold.
