# 搜索体验

用户已批准：输入建议、常用中英文同义词、匹配高亮；保持原始简介与现有页面结构。

沿用Ant Design Input与原搜索入口，使用轻量listbox，不引入搜索服务或额外组件库。候选最多2个任务和5个仓库；仓库候选沿用当前筛选排序，打开详情保留搜索和筛选。任务候选复用现有任务入口行为：清空搜索、重置类别、保留平台/收藏/排序。无输入不展示候选，无匹配不造推荐。提示候选类型并支持方向键、Enter、Escape、Tab与触摸；默认没有选中候选，Enter不强行打开第一个结果。中文组合输入期间只更新输入内容、不提交搜索或导航。

同义词限定为明确的科研意图，原始完整字符串匹配优先保留，不将仓库名拆词，不做模糊拼写和全网搜索。文献管理可匹配Zotero等工具，但搜Zotero不扩展到竞品；英文扩展词按词边界匹配，避免绘图命中configure之类单词。任务建议复用现有六个任务，不增加新的任务分类。

高亮只用React文本节点和mark，覆盖榜单仓库名、原始简介及候选名称；不改写或翻译原文、不使用innerHTML。大小写与全部原文字符保持一致，处理重叠词和正则特殊字符。深色/浅色使用现有暖色，仍保持首屏250kB预算及详情/图表等按需加载。
