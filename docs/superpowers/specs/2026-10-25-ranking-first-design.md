# 榜单优先与图表可读性

按用户已批准的结构优化：搜索与带计数任务胶囊（全部在首位）→统计→次级科研分类及平台/排序→有标题的紧凑新手路径→榜单→数据洞察。数据洞察移后，不同时默认折叠整块，保留手机其他三图按需展开。

任务按现有规则允许交叉匹配，分类是仓库主分类，统一命名科研分类并收进可展开的次级筛选。任务数量对应当前搜索/平台/收藏，忽略当前任务和分类以与点击任务重置分类的既有语义一致。零结果任务不可误导为有内容。新手路径默认单行横向入口，所有原始推荐依据、安装资料和适用人群收进展开内容；summary仅展开三角，不带外链箭头，正常文档状态仅详情显示，变化才在入口警示。

统计改近30天有推送，以数据快照的UTC日为锚，含当天29个此前自然日，排除无效和未来日期。趋势用窗口各仓库首个有效正数快照为基准增长率，保留日期/原Stars/起点说明及异常空态；三线用不同暖色与线型。分类环形图改带文字数量的横向条形图，支持鼠标和键盘筛选，不再重复中央总数。保留SVG、真实数据、原始简介、中文/英文、暖色、无障碍及首屏预算。
