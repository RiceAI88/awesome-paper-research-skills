# 各专业科研 Skills Implementation Plan

**Goal:** 基于已有榜单加入可追溯的专业筛选和真实专业统计。
**Architecture:** 独立专业目录配置与纯函数模块；筛选复用原domain；专业选择器位于hero与吸顶栏之间；专业图表模块复用现有延迟加载边界。
**Tech Stack:** React、Ant Design、现有SVG图表与Python采集流程，不增加依赖。
**Spec:** docs/superpowers/specs/2026-11-14-discipline-discovery.md

- [x] 1. 核对官方文档，建立学科、具体专业、专用/通用配置和依据；测试未知项目、重复专业、空专业计数。
- [x] 2. 接入URL状态、专业筛选、专业优先排序、任务计数、专业适配说明；测试通用开关、跨专业、重载分享、零结果。
- [x] 3. 专业数量和覆盖矩阵使用真实去重仓库数据，支持点击筛选；旧图表放入更多图表，继续支持懒加载、骨架屏和减弱动画。
- [x] 4. 扩展专业科研发现和README准入，记录规则及标签维护方式；运行Python边界测试。
- [x] 5. 桌面与窄屏视觉检查，运行相关单元/浏览器测试和构建，审查差异后发布。

验收：不伪造分类/数量；不覆盖原文简介；通用项目不膨胀专用计数；筛选与统计同口径；中英文和移动端可用；旧链接与旧图表保留。

## 验收记录

- 首批29个项目文档核对，保留原简介，不代表安装或专业任务实测。
- 专业索引与来源明细拆分，来源仅在打开详情时加载；手机首包保持低于250kB既有预算。
- Ruling: 专业数量、覆盖矩阵和收录少方向使用去专业/任务后的比较基数，保留搜索/平台/收藏/日期等条件。点击时选择对应专业/任务并关闭通用，保证图上数字能对应点击结果；增长和旧图继续跟随当前完整筛选。
- 独立复核修正计数跳转及英文排序说明；专业门类按唯一仓库计数。
- 50项前端逻辑、98项Python测试、178项浏览器回归通过；生产构建通过，桌面、390px中文及320px英文暗色视觉检查完成。

- 手机端门类为横向导航，选中项自动滚动到可见区域；额外34项涉及移动端与专业流程的回归通过。

- 云端首次检查发现首包压缩大小超出250kB预算约1kB：将底部精选组件改为接近视口时加载，保留路径入口与加载占位，不提高既有预算；补充延迟加载回归。
- 延迟精选后完整浏览器回归176项通过、3项旧测试需等待精选进入视口；补齐滚动步骤后16项相关回归全部通过，50项逻辑测试继续通过。
- 云端后续仍超首包预算约1kB：仅延迟精选的收益有限，进一步按实际使用组件裁剪官方Ant Design中英文语言包，移除未使用的日期、表单等文本；构建gzip下降约2.5kB。修正浏览测试滚动后定位主搜索框的顺序；27项相关回归、50项逻辑测试通过。
